# DTC NEXIS — مكتبة أكواد الأعطال والمعلومات الفنية

هذا المستودع هو المصدر المركزي لحفظ بيانات أكواد أعطال السيارات ومراجعها الفنية الخاصة بمشروع DTC NEXIS.

## المحتوى الحالي
- [المكتبة المركزية الدائمة](data/master/) — فهارس الأكواد وبيانات الشركات والمصادر وسجلات المراجعة.
- [دليل المكتبة وحالة البيانات](data/master/README_AR.md) — يعرض تقارير الحفظ السابقة والروابط إلى الملفات الرئيسية.
- [بيانات Volkswagen](volkswagen/) — مجموعات فنية محفوظة ومراجعات ذات صلة.
- [فحص سلامة البيانات](.github/workflows/verify-permanent-master.yml) — يتحقق من بنية المعلومات؛ لا ينشرها إلى الموقع تلقائياً.

## سياسة الحفظ والتحديث
- لا تُحذف الأكواد أو الأصول أو المعلومات الفنية المعتمدة بسبب تغيير المنصة.
- المعلومات غير المكتملة أو المتعارضة تُحفظ للمراجعة، ولا تُنشر باعتبارها مؤكدة.
- تحديث مكتبة الأكواد للموقع هدف منفصل عن تحديث تصميم الموقع وبرمجته، ولا يُعد مُفعّلاً لمجرد حفظ ملف هنا.
- Google Drive للنسخ الاحتياطية والأرشفة، وليس مصدراً حياً لبيانات الموقع.

## حالة تطبيق Windows
توقّف تطوير برنامج Windows لصالح موقع DTC NEXIS. أُزيلت ملفات بناء ونشر المثبّت القديمة من الفرع النشط؛ وقد تبقى إصدارات تاريخية في GitHub Releases وسجل Git إلى أن تُراجع على نحو مستقل. لا يعني هذا الملف اكتمال تنظيف التاريخ أو تفعيل نظام التحديث التلقائي للموقع.

> بيانات المكتبة تراكمية، وأرقام السجلات التاريخية ليست بالضرورة عدد أكواد فريدة أو معلومات مكتملة التحقق الفني.

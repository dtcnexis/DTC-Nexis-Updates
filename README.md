# DTC NEXIS — تحديثات Windows

هذا المستودع العام مخصص لملفات التثبيت التجريبية وقائمة التحديث الموقّعة ومفتاح التحقق العام. كود التطبيق وبيانات الورشة ومفتاح التوقيع الخاص غير موجودة هنا.

تتوفر نسخة البدء من قسم **Releases**. ثبّتها يدويًا مرة واحدة عند الانتقال من النسخة القديمة؛ بعدها استخدم زر **فحص التحديثات** داخل البرنامج. عند توفر إصدار أحدث يظهر خيار **تنزيل وتثبيت التحديث**، ويتحقق البرنامج من توقيعه وبصمته ويحفظ نسخة احتياطية من الأرشيف قبل بدء التثبيت.

ملف `update-feed.json` هو القناة العامة الثابتة. ينشره مسار الإصدار بعد التحقق من توقيع المالك ورفع ملف التثبيت الدائم. ملف `update-public-key.json` عام وآمن للمشاركة. لا يُرسل مفتاح التوقيع الخاص إلى هذا المستودع أو إلى البرنامج.

هذه نسخة تجريبية عامة. الصور توضيحية لمجموعة محددة من أكواد الأعطال، ولا تثبت موقع قطعة أو سبب عطل لسيارة معينة.

# DTC NEXIS — مكتبة البيانات الدائمة (المصدر المعتمد للحفظ)

**قرار المالك — 29 أكتوبر 2026:** الأكواد والتعريفات والترجمات ومراجع البيانات التي جُمعت تُحفظ بشكل **دائم وتراكمي**. البرنامج فقط يظل بمرحلة اختبار Windows؛ **المعلومات لا تعاد من الصفر ولا تُحفظ كمخرجات GitHub Actions مؤقتة**.

## ملفات هذه المكتبة
- [dtc_text_catalog.json](dtc_text_catalog.json): **المكتبة النصية الدائمة القابلة للتوسعة**. البداية **26 كوداً** مع EN/AR/SV (P=22 وU=4). جاءت من حزمة v10 الموجودة سابقاً؛ تم الحفاظ على التعريفات والترجمات كما هي مع مرجع SHA للأصل. **حفظ المعلومة ≠ التحقق الفني النهائي من كل تعريف ≠ اعتماد إرسالها للبرنامج**. لا يتم حذف الحقول أو الرموز عند وجود التباس؛ يضاف وضع المراجعة.
- [source_registry.json](source_registry.json): فهرس دائم بمواضع **11 ملف شركة من أرشيف المصادر الخاصة (934 سجل مراجعة)**، وبصمات Git الدقيقة لكل أصل، ومرجع Volkswagen VW022 (644 مرشحاً)، وفهرس Library (488 مدخلاً)، وبعض مجموعات C وDS. **الأرقام تتداخل ويُمنع جمعها كعدد أكواد فريدة أو مؤكدة**. الملفات الأصلية تظل في مواقعها الخاصة، ولا تُنسخ إلى هذا المستودع العام بلا موافقة حقوق وخصوصية.

## سياسة الإضافة من الآن
1. **الحفظ أولاً:** كل مجموعة جديدة تُفهرس فوراً باسم المصدر والبصمة وتاريخ التدقيق، ثم تُضم السجلات التي أمكن استخراجها إلى المسار الدائم المناسب. لا ملفات استيراد مؤقتة تكون المصدر الوحيد.
2. **عدم فقد المعلومات:** لا حذف للقديم عند التصحيح. يُستعمل تاريخ Git + مراجعة/تعديل للسجل نفسه مع حفظ الأصل، وتُزال التكرارات **من عرض التطبيق فقط** بعد التأكد، وليس بإتلاف المصدر.
3. **مستوى الدقة مستقل عن ديمومة الحفظ:** فهرس/مرشح/مصدر مطابق/تحقق فني OEM. لا ننسب معاني أكواد مصنع لمحرك معيّن قبل وجود دليل مناسب. الترجمة غير المراجعة تبقى موسومة.
4. **الصور:** روابط ومراجع رخصة فقط عند الحاجة؛ لا ننقل صور مواقع أو أدلة مملوكة للغير إلى GitHub.
5. **البرنامج والتحديث شيء مختلف:** هذا المجلد ليس قناة تحديث؛ لا يُحمّل التطبيق البيانات منه تلقائياً لمجرد إضافتها. عندما تُعتمد حزمة محددة، تُخدم عبر زر التحديث الواحد، قناة مالك واحدة وتوقيع P-256 وبصمة SHA-256 بعد اختبار Windows وموافقة المالك.
6. **لا تعديل للواجهة:** بطاقات P/B/C/U ودليل السيارة والصيانة والخدمات والمعرض كما هي. التحديث المرئي المتفق عليه محصور بنتائج DTC.

**قاعدة العمل:** أي ملف تصفه تقارير قديمة بأنه `review` أو `staging` لا يعني أنه يُحذف أو يعاد جمعه؛ هذا وصف لمستوى توثيق محتواه، وليس لمدة الاحتفاظ به. نحتفظ بالأصل دائماً ونكمل عليه.

**لا تُعدل دون موافقة منفصلة:** `update-feed.json` و`pending-update-feed.json` و`release-request.json` و`owner-channel/update-feed.json` ومفاتيح التوقيع أو ملفات تثبيت التطبيق.
